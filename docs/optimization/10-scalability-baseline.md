## 분석

### 성능 저하 원인 (가설)
1. **올인원 아키텍처**: App + MySQL + Redis가 CPU 2코어를 경합 → 처리량 병목
2. **데이터 규모 증가**: 좋아요 620만건, 팔로우 54만건 → WHERE IN 쿼리 비용 증가
3. **네트워크 지연**: 로컬→GCP ~100ms 포함 (로컬 테스트 대비 핸디캡)
4. **포스트 생성 0%**: 원인 미확인 — 별도 조사 필요

### 주목할 점
- 모든 API의 p95가 **7~8초대**로 수렴 → CPU 포화 시 전반적 성능 저하
- 피드 ALL이 피드 CORE보다 ~1초 느림 → 팔로잉 수에 따른 WHERE IN 비용 차이 시사
- 에러율 9.67%는 대부분 타임아웃 또는 커넥션 풀 고갈로 추정
