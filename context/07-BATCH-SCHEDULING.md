# 배치 & 스케줄링

## 스케줄러 목록

### 1. BatchScheduler

일간/월간 배치 작업을 담당합니다.

| 작업 | 주기 | 설명 |
|------|------|------|
| 일간 통계 생성 | 매일 | 시간대별 답변 수 집계 |
| 월간 질문 통계 | 매월 | 월별 질문 사용 통계 |
| 선택 일기 통계 | 매월 | DiaryWho/Where/What 통계 |
| 월간 디스크 생성 | 매월 초 | 전체 회원에 대해 새 월별 디스크 생성 |

### 2. NotificationScheduler

알림 발송 스케줄링을 담당합니다.

| 작업 | 주기 | 설명 |
|------|------|------|
| 일일 리마인더 | 매일 설정 시간 | 저널 작성 리마인더 발송 |
| 미답변 질문 알림 | 주기적 | 미답변 질문 리마인더 |
| 임시 저장 알림 | 주기적 | 발행되지 않은 임시 게시글 알림 |

### 3. NotificationReminderScheduler

사용자별 알림 리마인더 설정에 따라 알림을 발송합니다.

| 설정 | 옵션 |
|------|------|
| 빈도 | Daily, Weekly, Monthly, Off |
| 시간 | 사용자 설정 |

## 통계 생성 (ReportStat)

### 일간 통계
- 시간대별 답변 작성 수 집계
- 어떤 시간에 주로 기록하는지 분석

### 월간 통계
- 가장 많이 답변한 질문 카테고리
- 선택 일기 패턴 분석
- 월간 활동 요약

## 비동기 처리 (AsyncConfig)

알림 전송 등 무거운 작업은 `@Async`로 비동기 실행:
- FCM 푸시 전송
- 이메일 발송
- 통계 업데이트
